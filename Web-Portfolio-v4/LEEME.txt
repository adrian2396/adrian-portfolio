PORTFOLIO DE ADRIÁN VIZCAÍNO · v4 (TERMINAL)

Abrir index.html con doble clic. No requiere instalación, servidor ni conexión.
Mantener index.html, styles.css, main.js y la carpeta assets juntos.
El acceso al currículum utiliza ../CV/Adrian_CV.html.
Las versiones anteriores siguen en ../Web-Portfolio y ../Web-Portfolio-v3.

CONCEPTO
Un terminal de fósforo ámbar: una sola columna, cada sección empieza con un
comando que se escribe al llegar a ella (cat perfil.txt, ls proyectos/,
adrian --help, git log...). Un único color de acento y dos tipografías:
VT323 (fuente del terminal DEC VT320) para títulos e IBM Plex Mono para leer.
El botón "crt:on" de la cabecera apaga las líneas de barrido y el brillo.

SECCIONES
Inicio: líneas de arranque [ OK ], whoami y el nombre impreso letra a letra.
  Abajo, una línea UART transmite el nombre byte a byte (pasa el cursor).
Perfil: texto que se ilumina con el scroll y ficha clave ...... valor.
Proyectos: una ventana de terminal por producto, con pestañas
  [vídeo] [fotos] [esquema] según el material disponible.
Servicios: oferta freelance en formato --help y el proceso en 4 pasos.
Stack: capas L1–L5; se resalta la que estás leyendo.
Trayectoria: formato git log, de v0.x (formación) a v4.0 (ORBIS).
Investigación y contacto.

FORMULARIO "NUEVO PROYECTO"
Se abre desde la cabecera, el inicio, servicios y contacto. También con
el enlace index.html#brief. Pide contacto, tipo de proyecto, stack, fase,
alcance, plazo, presupuesto orientativo y descripción.
Por defecto prepara un resumen y abre el programa de correo del cliente
con todo rellenado (también puede copiarlo).
Para recibir los mensajes directamente, configura briefConfig al principio
de main.js con un servicio gratuito de formularios:
  Web3Forms: pide una clave en web3forms.com con tu correo y pon
    endpoint: 'https://api.web3forms.com/submit',
    fields: { access_key: 'TU-CLAVE' }
  Formspree: crea un formulario en formspree.io y pon
    endpoint: 'https://formspree.io/f/TU-ID'

FOTOS Y VÍDEO
Guarda las fotos en assets/media/ y añade sus rutas en productMedia, al
principio de main.js. Para un vídeo, pega el enlace de YouTube.
El vídeo se carga solo al pulsar "reproducir" (youtube-nocookie).
Canal de ORBIS: https://www.youtube.com/channel/UCdI4mP0ZrDqYjwylDZQd21w

FUENTES DE LOS DATOS DE PRODUCTO
ANC +: ficha técnica de ORBIS.
ASTRO LUM: ficha técnica de ORBIS y Interempresas, "Gestión IoT y
  conectividad híbrida para el alumbrado público".
XEO LUM +: Interempresas, "ORBIS presenta Xeo Lum +, para la telegestión
  de alumbrado".
La variante gateway de ASTRO LUM procede de la descripción de Adrián.
Los esquemas son conceptuales, con valores simulados; así se indica bajo
cada uno.
